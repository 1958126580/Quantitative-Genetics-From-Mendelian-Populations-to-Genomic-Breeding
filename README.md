数量遗传学研究连续变异性状的遗传规律，是动植物育种与复杂性状遗传 研究的理论基础。本书以“从孟德尔群体到基因组育种”为主线，系统阐 述群体遗传结构与连锁不平衡、遗传连锁图谱与数量性状位点定位、全基 因组关联研究、遗传方差分解与亲属相似性、遗传参数估计、选择理论与 选择指数、遗传漂变与近交、杂种优势与杂交育种、最佳线性无偏预测与 混合模型、基因组遗传力与基因组预测，以及多组学、基因与环境互作和 智能育种等前沿方向。 全书十篇三十七章，重要公式均给出完整推导，每章配有数值例题、 习题与参考解答，计算程序与资料按章独立提供。可作为遗传育种、数量 遗传学与统计基因组学专业研究生教材，亦可供相关领域科研人员参考。
