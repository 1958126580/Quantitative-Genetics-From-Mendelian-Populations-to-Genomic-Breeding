数量遗传学研究连续变异性状的遗传规律，是动植物育种与复杂性状遗传 研究的理论基础。本书以“从孟德尔群体到基因组育种”为主线，系统阐 述群体遗传结构与连锁不平衡、遗传连锁图谱与数量性状位点定位、全基 因组关联研究、遗传方差分解与亲属相似性、遗传参数估计、选择理论与 选择指数、遗传漂变与近交、杂种优势与杂交育种、最佳线性无偏预测与 混合模型、基因组遗传力与基因组预测，以及多组学、基因与环境互作和 智能育种等前沿方向。 全书十篇三十七章，重要公式均给出完整推导，每章配有数值例题、 习题与参考解答，计算程序与资料按章独立提供。可作为遗传育种、数量 遗传学与统计基因组学专业研究生教材，亦可供相关领域科研人员参考。
习题集的编写是一场漫长的检验。每写一道题，我都问自己：这个数字我能复算吗？这个结论的条件写清楚了吗？读者做错时，错在哪一步？为了回答这些问题，全书的数值题都配有可运行的程序，程序里的每一个断言都是一次与理论的对质：理论值与模拟值是否吻合、一个恒等式是否在数值上成立、一个界是否被违反。有几次，程序的结果与我原先的设想不同，例如某一设计下的约束从未起作用，某个估计量的偏差比预期更大，这些发现都被如实写进了答案，因为数量遗传学的价值不在于每个公式都完美，而在于知道每个公式何时不完美。
数量遗传学正在被数据与算力快速改变，但它的底层逻辑没有变：把机制写成模型，由模型推出可检验的结论，再用资料去检验。愿这本习题集成为读者与这门学科之间的一个练习场，也愿读者在这里算错的每一道题，都成为通向理解的一级台阶。
